# WS-Mask2Former Inference Server

## Overview

This document describes the Dockerized inference server for the weight-sharing Mask2Former model trained on ADE20K semantic segmentation. The server provides:

- **Instance segmentation** with bounding box output
- **Subnet switching** (min/middle/max) for latency-accuracy tradeoffs
- **Label mapping** from ADE20K (150 classes) to Pylot AV detection classes

## Architecture

### Model Components with Subnet Switching

| Component | Type | Subnet Switching | Notes |
|-----------|------|------------------|-------|
| Backbone | ResNet50 | No (fixed) | Standard detectron2 ResNet |
| Pixel Decoder | MSDeformAttnTransformer | **Yes** (depth 0/1/2) | Elastic encoder layers |
| Predictor | MultiScaleMaskedTransformerDecoder | **Yes** (depth 0/1/2) | Elastic decoder layers |

> **Note on Backbone**: The trained model uses a fixed ResNet50 backbone. The codebase supports SNNet (elastic Swin Transformer) with TINY/SMALL/BASE variants, but this would require training a new model with `MODEL.BACKBONE.NAME: "SNNet"`. The current subnet switching operates only on the transformer layers.

### Subnet Configurations

```
min:    pixel_decoder=[0], predictor=[0]  -> Fastest, fewer detections
middle: pixel_decoder=[1], predictor=[1]  -> Balanced
max:    pixel_decoder=[2], predictor=[2]  -> Slowest, best accuracy
```

## Quick Start

### 1. Build the Docker Image

```bash
cd /home/saketh/marko/wsobjdet
./test_inference.sh build
```

Build takes ~5-10 minutes (compiles CUDA ops for MultiScaleDeformableAttention).

### 2. Run Inference on an Image

```bash
# Basic inference with max subnet
./test_inference.sh infer -i /path/to/image.jpg -s max

# With lower detection threshold
./test_inference.sh infer -i /path/to/image.jpg -s max -t 0.1

# Use built-in test image
./test_inference.sh infer -s min
```

### 3. Benchmark All Subnets

```bash
./test_inference.sh benchmark -i /path/to/image.jpg
```

### 4. Compare All Subnets (with Artifacts)

```bash
# Generates: visualizations, JSON results, CSV summary, text report
./test_inference.sh compare -i /path/to/image.jpg -o ./results
```

### 5. Print ADE20K Label Mapping

```bash
./test_inference.sh labels
```

### 6. Interactive Shell

```bash
./test_inference.sh shell
```

## Test Script (test_inference.sh)

The `test_inference.sh` script provides an easy interface for common operations:

```
Usage: ./test_inference.sh <command> [options]

Commands:
  build       Build the Docker image
  labels      Print ADE20K label mapping
  infer       Run inference on a single image
  benchmark   Run latency benchmark across all subnets
  compare     Run all subnets on same image, save visualizations
  shell       Start interactive shell in container

Options:
  -i, --image PATH      Input image path (default: input.jpg in container)
  -o, --output-dir DIR  Output directory for results (default: ./results)
  -s, --subnet NAME     Subnet: min, middle, max (default: max)
  -t, --threshold NUM   Min detection score 0-1 (default: 0.1)
  -h, --help            Show this help
```

### Artifacts Generated by `compare` Command

| File | Description |
|------|-------------|
| `{image}_min.jpg` | Visualization with min subnet |
| `{image}_middle.jpg` | Visualization with middle subnet |
| `{image}_max.jpg` | Visualization with max subnet |
| `{image}_min.json` | Full detection results (JSON) |
| `{image}_middle.json` | Full detection results (JSON) |
| `{image}_max.json` | Full detection results (JSON) |
| `results.csv` | Summary: subnet, latency_ms, num_detections |
| `comparison_report.txt` | Complete text report |

## Command Line Options (inference_server.py)

```
usage: inference_server.py [-h] [--config CONFIG] [--weights WEIGHTS]
                           [--image IMAGE] [--output OUTPUT]
                           [--subnet {min,middle,max}] [--device DEVICE]
                           [--min-score MIN_SCORE] [--min-area MIN_AREA]
                           [--benchmark] [--print-labels] [--json]

Options:
  --config CONFIG       Path to config.yaml (default: sem_ade_output_2/config.yaml)
  --weights WEIGHTS     Path to model weights (default: sem_ade_output_2/model_final.pth)
  --image IMAGE         Path to input image (any resolution JPG/PNG)
  --output OUTPUT       Path to save visualization with bounding boxes
  --subnet {min,middle,max}  Subnet configuration (default: max)
  --device DEVICE       Device (default: cuda:0)
  --min-score MIN_SCORE Minimum detection score (default: 0.3)
  --min-area MIN_AREA   Minimum bounding box area in pixels (default: 200)
  --benchmark           Run latency benchmark across all subnets
  --print-labels        Print ADE20K class labels and exit
  --json                Output results as JSON
```

## Docker Image Details

- **Base Image**: `pytorch/pytorch:1.10.0-cuda11.3-cudnn8-devel`
- **Size**: ~15.6 GB
- **Key Dependencies**:
  - PyTorch 1.10 + CUDA 11.3
  - detectron2 v0.6
  - timm 0.6.13
  - setuptools 59.5.0 (required for detectron2 build)

### Why PyTorch 1.10?

The MultiScaleDeformableAttention CUDA extension requires compilation against PyTorch headers. PyTorch 1.10 + CUDA 11.3 provides the most stable build environment for detectron2 v0.6.

## Troubleshooting

### "No module named 'MultiScaleDeformableAttention'"

The CUDA ops weren't compiled. Rebuild the Docker image:
```bash
docker build --no-cache -t ws-mask2former .
```

### "CUDA out of memory"

Reduce image size or use a smaller subnet:
```bash
--subnet min
```

### Zero detections

1. Lower the score threshold: `--min-score 0.05`
2. Check if the image contains AV-relevant objects (cars, people, trucks, etc.)
3. The model was trained on ADE20K - it works best on street/outdoor scenes

### Slow first inference

The first inference includes model loading and CUDA warmup. Subsequent inferences are faster.

## Performance Notes

### Layer Configuration by Subnet

| Subnet | Encoder Layers | Decoder Layers | Total Elastic |
|--------|---------------|----------------|---------------|
| min | 4/6 | 7/9 | Skip 4 layers |
| middle | 5/6 | 8/9 | Skip 2 layers |
| max | 6/6 | 9/9 | All layers |

### Measured Latency (50 runs, RTX-class GPU)

**Raw model forward pass (640x349 image):**

| Subnet | Latency | Std Dev |
|--------|---------|---------|
| min | 25.52 ms | 1.88 ms |
| middle | 26.83 ms | 3.48 ms |
| max | 27.55 ms | 0.62 ms |

**Full inference with preprocessing:**
- 640x349 image: ~35-45 ms
- 1200x1600 image: ~75 ms

### Why the Latency Difference is Small (~8%)

1. **Backbone (ResNet50) dominates** - It's fixed and takes ~20-25ms
2. **Only 4 transformer layers are elastic** - 2 encoder + 2 decoder
3. **Each transformer layer costs ~0.5-1ms** - Small absolute difference

For larger latency differences (30-50%), the backbone would need SNNet (Swin Transformer) with elastic depth. The current model uses a fixed ResNet50.

### Image Resolution

Any resolution JPG/PNG works. Larger images = proportionally longer latency.
